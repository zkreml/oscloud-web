What it is

Trilium Next is an open source tool for hierarchical notes and a personal knowledge base. It is a web application with a desktop client available as well. Notes can be text, Markdown, code, tables or diagrams, and you can organise them in a tree.

What it can do

  • Tree structure of notes, one note can live in several places (cloning).
  • Encryption of selected notes.
  • Automatic versioning, so you can go back to an older version of a note.
  • Relation graphs between notes and full-text search.
  • Markdown, code, tables, diagrams and formulas.
  • Sync between the web and the desktop client.
  • JavaScript scripts for advanced users.

FAQ

How do I order?
You fill in the join request, choose Trilium Next and monthly or yearly payment. We set up the instance by hand and reply by e-mail.
Can I have my own domain?
Yes, for example notes.yourdomain.com. It is arranged individually after you order.
What if I need more than 5 GB?
Write to us and we will work it out. Larger storage is arranged individually.
Where is the guide?
The Trilium Next documentation describes the features, compares it with other tools and covers setup.
Are my notes safe?
Every customer has their own separate instance and we back up the data. You can additionally encrypt sensitive notes in Trilium. It is a good idea to back up important data outside OSCloud as well.
