Matrix — mxchat.cz

Komunitní chat na otevřeném decentralizovaném protokolu Matrix. Bez reklam, bez sledování, a můžeš si povídat i s lidmi z jiných Matrix serverů.

Otevřít chat Dokumentace

Co je Matrix

Matrix je otevřený protokol pro chat, podobně jako e-mail: máš účet na jednom serveru, a přesto píšeš s lidmi na jakémkoli jiném. Náš server je mxchat.cz, takže tvoje adresa bude vypadat jako @jmeno:mxchat.cz.

Jak začít

  1. Otevři chat.mxchat.cz, to je webový klient Element.
  2. Vytvoř si účet na serveru mxchat.cz.
  3. Připoj se do místností a piš.

Aplikace

Web stačí, ale na mobilu a počítači je pohodlnější aplikace. Funguje jakýkoli Matrix klient, třeba Element nebo FluffyChat. Při přihlášení zadej jako domovský server https://mxchat.cz.

Podpora OSCloud běží přes Matrix, takže se na nás můžeš obrátit rovnou tady. Pro cokoli oficiálního je tu info@oscloud.cz.
